---
titre: Mesure principale d’un angle
type: application
notion: Mesure principale
difficulte: Moyen
ordre: 4

enonce: |
  Déterminer la mesure principale (dans $\interof{-\pi}{\pi}$) de chacun des angles suivants.

  1. $\dfrac{13\pi}{3}$
  2. $-\dfrac{7\pi}{4}$
  3. $\dfrac{25\pi}{6}$
  4. $\dfrac{100\pi}{3}$

indices:
  - |
    Piste générale : retranche ou ajoute des multiples de $2\pi$ jusqu’à tomber dans $\interof{-\pi}{\pi}$.
  - |
    Plus précis : pour la 4, $\dfrac{100\pi}{3} = 33\pi + \dfrac{\pi}{3}$. Cherche le nombre de tours complets : $\dfrac{100\pi}{3} - 2k\pi$ avec $k = 17$.

correction: |
  **1.** $\dfrac{13\pi}{3} - 4\pi = \dfrac{\pi}{3}$.

  **2.** $-\dfrac{7\pi}{4} + 2\pi = \dfrac{\pi}{4}$.

  **3.** $\dfrac{25\pi}{6} - 4\pi = \dfrac{\pi}{6}$.

  **4.** $\dfrac{100\pi}{3} - 34\pi = \dfrac{100\pi - 102\pi}{3} = -\dfrac{2\pi}{3}$, qui est bien dans $\interof{-\pi}{\pi}$.
